## Direct fan and fan-group targets for clock actions

Both `freshpoint.set_current_datetime` and `freshpoint.set_datetime` now accept Home Assistant targets. Select a Freshpoint fan or a fan group directly in the action editor. Groups are expanded by Home Assistant; their Freshpoint devices are deduplicated, so each device is written once.

Existing automations using `data.device_id` continue to work. Disabled live clock entities remain disabled, and neither action requires the clock or button entity to be enabled.

When several devices are selected, the action attempts all of them even if one fails. It reports a combined error afterward instead of silently reporting success. Groups containing other integrations control only their Freshpoint fan members; an empty or unsupported selection raises an error.

No changes to fan power, speed, heating, schedules or global Recorder filters are made by this update. Setting a device clock can affect its existing weekly schedule.
